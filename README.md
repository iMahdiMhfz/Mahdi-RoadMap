# خارطة مهدي المالية

تطبيق ويب بالعربي لتخطيط المال على مدى 24 شهراً (تشرين الثاني 2026 ← تشرين الأول 2028)، والأولوية فيه لهدف ادخار السيارة.

## المميزات
- واجهة عربية كاملة (RTL) بخط **IBM Plex Sans Arabic**
- ثلاث خطوات: اختيار السنة ← اختيار الشهر ← متابعة الدفعات
- حساب ادخار السيارة تلقائياً من الدخل المتبقي بعد المصاريف والأهداف
- صفحة للأهداف، ولوحة تحليلات فيها رسم بياني، وصفحة إعدادات للدخل
- حفظ محلي، وتصدير نسخة احتياطية واستيرادها (JSON)، وزر تراجع

## التشغيل
الموقع كله ملف واحد هو `index.html`، ولا يحتاج أي تثبيت. افتحه مباشرة بالمتصفح.

## النشر على GitHub Pages
1. ارفع `index.html` إلى الـ repo
2. افتح **Settings ← Pages**
3. من **Source** اختر `Deploy from a branch`، ثم اختر الفرع `main` والمجلد `/ (root)`
4. اضغط Save، وبعد دقيقة يصير الموقع على:
   `https://USERNAME.github.io/REPO-NAME/`

> ملاحظة: البيانات محفوظة في متصفّحك فقط، فخذ نسخة احتياطية بشكل منتظم.
